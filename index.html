PRANSTAMBH / SYSTEM FLOW

How PRANSTAMBH Works

An AI-powered wildlife detection and highway safety intelligence system.

01

Wildlife Detection

Cameras installed near highway and wildlife-prone areas continuously monitor the surroundings. When an animal enters the camera view, the AI-based detection system identifies the animal in real time.

02

AI Identification

The AI model determines which animal has been detected and provides a confidence score indicating how confident the model is about the detection.

03

Detection Data

Each detection is recorded with important information such as animal, camera, confidence, date, risk, status and time.

04

Firebase Cloud Storage

Detection records are stored in Firebase Firestore. This allows the PRANSTAMBH dashboard to receive and display detection information in real time.

05

Risk Assessment

The system classifies the detected event according to its risk level. The dashboard displays the current risk along with the detection status.

06

Warning & Alert

When an event requires attention, its alert status can be reflected on the PRANSTAMBH monitoring dashboard so that the situation can be observed and acted upon.

07

Wildlife Analytics

Historical detection records are analyzed to understand animal frequency, risk distribution, camera activity, detection dates and peak wildlife activity.
